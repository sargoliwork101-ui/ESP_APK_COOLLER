# اپ اندروید کولر هوشمند ESP32

این پوشه شامل دو بخش کاملاً جداست:

- `firmware/Cooler_ESP32_WROOM_final.ino` — نسخه‌ی جدید فرم‌ور برد (باید دوباره روی ESP32 آپلود شود)
- `www/index.html` — کل ظاهر و منطق پنل که حالا به‌جای اجرا روی برد، داخل یک اپ اندروید اجرا می‌شود
- بقیه‌ی فایل‌ها (`capacitor.config.json`, `package.json`, `.github/workflows/...`) فقط برای ساخته‌شدن خودکار APK در گیت‌هاب هستند

**ظاهر و منطق هیچ تغییری نکرده‌اند** — فقط محل اجرای HTML/JS از برد به گوشی منتقل شده.

---

## مرحله ۱ — آپلود فرم‌ور جدید روی ESP32

1. در Arduino IDE، فایل `firmware/Cooler_ESP32_WROOM_final.ino` را باز کن.
2. **مهم:** فایل `webpage.h` قدیمی را از پوشه‌ی پروژه حذف کن (یا اصلاً پوشه‌ی `firmware` را جای پوشه‌ی قبلی پروژه‌ات استفاده کن) — چون دیگر لازم نیست و اگر باقی بماند فقط فضای فلش را اشغال می‌کند، اما چون دیگر جایی `#include` نشده، مشکلی هم در کامپایل ایجاد نمی‌کند.
3. مثل قبل کامپایل و آپلود کن.
4. بعد از آپلود، دیگر با مرورگر گوشی به آدرس برد نمی‌روی؛ به‌جایش از اپی که در مراحل بعد می‌سازیم استفاده می‌کنی. (اگر با مرورگر به آدرس برد بروی، دیگر صفحه‌ای نمایش داده نمی‌شود — این طبیعی و مطابق هدف است.)

---

## مرحله ۲ — ساخت ریپازیتوری در گیت‌هاب

1. یک ریپازیتوری جدید در گیت‌هاب بساز (خصوصی یا عمومی، فرقی نمی‌کند).
2. کل محتوای این پوشه (`cooler-app/`) — به‌جز `firmware/` که فقط برای خودت است و نیازی نیست حتماً پوش شود، ولی مشکلی هم ندارد — را داخل ریپو کپی کن.
3. در VS Code، ترمینال را باز کن و این دستورات را بزن (به جای `<repo-url>` آدرس ریپوی خودت را بگذار):

```bash
git init
git add .
git commit -m "اپ اندروید کولر هوشمند ESP32"
git branch -M main
git remote add origin <repo-url>
git push -u origin main
```

---

## مرحله ۳ — ساخته‌شدن خودکار APK (بدون نیاز به Node یا Android Studio روی سیستم خودت)

به‌محض push شدن، در گیت‌هاب برو به تب **Actions** ریپو؛ یک اجرا به اسم «Build Android APK» شروع می‌شود (حدود ۳ تا ۵ دقیقه طول می‌کشد). این workflow کاملاً روی سرورهای گیت‌هاب:

- Node.js و JDK را نصب می‌کند
- پروژه‌ی اندروید کاپاسیتور را می‌سازد
- پچ لازم برای اجازه‌ی ارتباط HTTP ساده با برد را اعمال می‌کند
- با Gradle، فایل APK را می‌سازد

وقتی اجرا با علامت ✅ سبز تمام شد، روی همان اجرا کلیک کن؛ پایین صفحه بخش **Artifacts** را می‌بینی — یک فایل zip به اسم `cooler-esp32-app-debug-apk` آنجاست. دانلودش کن، از حالت zip خارجش کن، فایل `app-debug.apk` داخلش هست.

## مرحله ۴ — نصب APK روی گوشی

1. فایل `app-debug.apk` را به گوشی اندرویدی منتقل کن (تلگرام به خودت، ایمیل، کابل و...).
2. رویش بزن تا نصب شود. چون از گوگل‌پلی نیست، اندروید یک هشدار «منبع ناشناس» می‌دهد؛ اجازه‌ی نصب را بده.
3. اپ را باز کن.

## مرحله ۵ — اتصال اپ به برد

1. گوشی را به وای‌فای خود برد (همان AP قدیمی، پیش‌فرض `ESP32_Timer_Hub`) وصل کن — دقیقاً مثل قبل.
2. اپ را باز کن. اگر ظرف چند ثانیه پیام «اتصال اولیه ناموفق» دیدی، وارد تب **تنظیمات (⚙)** شو، پایین صفحه بخش «آدرس برد» را پیدا کن و آدرس برد را بررسی/تنظیم کن (پیش‌فرض `http://192.168.4.1` درست است اگر مستقیم به AP برد وصلی).
3. بعد از آن، همه‌چیز دقیقاً مثل قبل کار می‌کند: خانه، سناریوها، وای‌فای — با همان ظاهر و همان منطق.

> نکته: این آدرس فقط یک‌بار لازم است تنظیم شود؛ در گوشی ذخیره می‌ماند.

---

## اگر بعداً خواستی چیزی در ظاهر/منطق اپ تغییر بدهی

فقط فایل `www/index.html` را در VS Code ویرایش کن، دوباره `git push` کن؛ گیت‌هاب خودش APK جدید را می‌سازد. نیازی به Android Studio یا نصب چیزی نیست.

## یک نکته‌ی امنیتی برای اطلاع

چون ارتباط اپ با برد از طریق HTTP ساده (نه HTTPS) است — دقیقاً مثل قبل که با مرورگر گوشی به برد وصل می‌شدی — تنظیم `network_security_config.xml` اجازه‌ی این نوع ارتباط را برای کل اپ باز کرده است. این محدود به همین اپ است و روی امنیت بقیه‌ی گوشی اثری ندارد؛ فقط یعنی این اپ خاص می‌تواند با سرورهای HTTP ساده هم صحبت کند (که لازمه‌ی کار کردن با خود برد است).
